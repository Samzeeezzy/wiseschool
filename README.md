# Wisdom International School of Excellence (WISE) Website

A responsive static website built with HTML, CSS and JavaScript.

## Brand palette
- Royal blue: `#1769C2` (primary)
- Golden yellow: `#F4C542` (highlight)
- Fresh green: `#36A66A` (supporting accent)

White and pale blue are used as neutral backgrounds. The palette was selected after reviewing the school's published photographs and visual identity.

## Included
- Responsive navigation and mobile menu
- Automatic hero slider and scrolling school notice
- WISE overview, vision, mission, goal and values
- All school levels: Crèche, Play-Pen, Pre-Nursery, Nursery, Primary, Junior Secondary and Senior Secondary
- Curriculum and STREAM information
- Community impact section covering the Tudun-Wada Eco-Toilet WASH project and 2024 World's Best School Prizes recognition
- 2026 Maltina Teacher of the Year recognition
- Admissions enquiry and contact links

## Files
- `index.html` — page content and structure
- `style.css` — layout, responsive styling and brand colours
- `script.js` — navigation and slider interactions

## Preview
Open `index.html` in a modern browser.

## Publish
Upload the contents of this folder to your GitHub repository or static hosting provider. Keep all three files in the same directory.

## Important notes
- The school photographs currently load from the official WISE website (`wiseschool.com.ng`). If you prefer the website to host its own photographs, download approved originals and update the image paths to local files.
- Check that the school is happy with the wording and recognition details before publishing.
- This is a static informational website. It does not yet include an online admission form, database, admin dashboard, payment system or CMS.
- Contact details included are the school's published phone number and email address. Confirm they are still current before launch.


## Official WISE image assets
- `assets/wise-school-logo.png` — official WISE crest, used in the header and footer.
- `assets/wise-world-best-school-top-10-2024.jpeg` — official 2024 Top 10 World’s Best School Prizes badge, featured in the school impact section.

Keep the `assets` folder alongside `index.html`, `style.css`, and `script.js` when uploading or deploying the website.
